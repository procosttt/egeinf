# Шаблоны ЕГЭ по информатике

Сайт с короткими разборами и готовыми шаблонами для 27 заданий ЕГЭ.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Изменение материалов

Шаблоны находятся в `data/part1.mjs` и `data/part2.mjs`. После изменения данных отправьте коммит в GitHub — подключённый к репозиторию проект Vercel развернёт новую версию автоматически.

## Проверка

```bash
npm test
npm run lint
npm run build
```

## Развёртывание на Vercel

Импортируйте репозиторий в Vercel. Платформа автоматически определит Next.js; переменные окружения, база данных и особые команды сборки не нужны.
